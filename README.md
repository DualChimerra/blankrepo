# LoRA Steps Calculator

Калькулятор шагов и просмотров для тренировки LoRA (sd-scripts / kohya_ss и совместимые тренеры). Electron-приложение для macOS.

## Запуск

Дважды кликните **`start.command`** — при первом запуске он сам установит зависимости (нужен установленный [Node.js](https://nodejs.org)) и откроет приложение.

> Если macOS блокирует запуск: правый клик по `start.command` → «Открыть». Либо разово: `chmod +x start.command`.

Вручную: `npm install && npm start`.

## Что умеет

- **Расчёт** итоговых шагов оптимизатора и просмотров из: количества картинок, `num_repeats`, эпох, `train_batch_size`, `gradient_accumulation_steps`.
  - Формулы: `просмотры = картинки × repeats × эпохи`; `шаги = просмотры / (batch × accum)` (с округлением батчей вверх, как в kohya).
- **Подсказки-ориентиры**: цветные бейджи по общему числу шагов (~1000–2500 для персонажа) и проходам на картинку (~100).
- **Пропорции**: сохраните удачную конфигурацию — при её применении включается «режим пропорции». Меняете любой параметр (например, в новом датасете другое число картинок) — остальные автоматически подбираются так, чтобы удержать целевые шаги и/или проходы на картинку.
  - Что именно держать — переключатель «шаги / проходы на картинку / баланс».
  - Любой параметр можно **заблокировать** (🔒) — автоподбор его не тронет.
- **Копирование сводки** в буфер — удобно вставлять в заметки к тренировке.

Все данные (текущие значения, блокировки, пропорции) сохраняются локально между запусками.
